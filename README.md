# Trawl

Trawl is the directed acquisition and search closure for perish.code.

Its long-term direction combines a small Google-shaped information loop with
collection beyond HTTP. Its actual construction is constrained by enumerable
acquisition needs inside perish.code, so the direction cannot expand into a
general platform without consumer pressure.

## Status

The repository is entering the Plumb skeleton. Its initial Rust library anchor
is intentionally empty. Source, observation, artifact, corpus, index, ranking,
adapter, scheduler, and consumer contracts remain open until the cold-start
discussion identifies the first complete scenario.

Noema is one possible consumer. Trawl is independently useful and does not use
Noema as its storage or product boundary.

The current boundary brief lives in
[docs/architecture.md](docs/architecture.md).
